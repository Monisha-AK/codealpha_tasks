# CodeAlpha Internship Tasks
CodeAlpha C Programming Internship Tasks
This repository contains the tasks completed as part of the CodeAlpha C Programming Internship.


## Projects

### 1. Calculator
A menu-driven calculator developed using C programming and switch-case statements.

### 2. Matrix Calculator
A matrix calculator that performs operations such as:
- Addition
- Subtraction
- Multiplication
- Transpose
- Determinant Calculation
- Identity Matrix Check
- Symmetric Matrix Check

### 3. Student Management System
A menu-driven student management system developed in C using structures and binary file handling.

#### Features
- Add Student Records
- Display Records
- Search Records
  - Search by Roll Number
  - Search by Name
  - Search by Department
  - Search by Year
- Update Records
- Delete Records
- File Storage

## Technologies Used

- Structures

- Dynamic Memory Allocation
